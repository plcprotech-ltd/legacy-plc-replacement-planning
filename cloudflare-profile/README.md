# PLCProTech Engineering — Cloudflare Profile

Static technical profile intended for Cloudflare Pages.

## Deployment

Connect this GitHub repository to Cloudflare Pages and use:

- Production branch: `main`
- Root directory: `cloudflare-profile`
- Build command: none
- Build output directory: `.`

The directory contains only static files and does not require a framework or package manager.

## SEO / GEO

The profile includes:

- descriptive title and meta description
- index/follow robots directives
- Organization + ProfilePage structured data
- public GitHub `sameAs` relationship
- explicit technical scope and maintainer identity
- `robots.txt`
- `llms.txt`

After Cloudflare assigns the final `pages.dev` URL, add that URL as the canonical URL and sitemap target if desired.

## Purpose

This profile is a technical identity page for PLCProTech Engineering. It links to genuine public engineering projects and keeps commercial language minimal.
