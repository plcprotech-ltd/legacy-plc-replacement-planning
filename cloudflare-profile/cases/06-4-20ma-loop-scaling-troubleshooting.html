Analog signal troubleshooting

Check 4–20 mA scaling before changing hardware.

Use this field calculator to convert measured loop current into engineering units, calculate the expected current for a process value and estimate the resistance budget available to a two-wire transmitter loop.

Verify the transmitter range, loop supply, input-card configuration and manufacturer documentation before changing wiring or scaling. Fault-current conventions vary by device and configuration.

Measured current → process value

Process value: 50

Formula: PV = LRV + ((mA − 4) / 16) × (URV − LRV).

Process value → expected current

Expected current: 12.000 mA

Formula: mA = 4 + 16 × ((PV − LRV) / (URV − LRV)).

Loop resistance budget

Estimated available loop resistance: 550 Ω

The estimate assumes a 20 mA full-scale current: R = (supply voltage − minimum transmitter voltage − reserved margin) / 0.020. Include input resistance, barriers, isolators and cable resistance in the real loop total.

Field fault-isolation sequence

1. Confirm the configured range

Record the transmitter LRV and URV. Do not assume the PLC scaling matches the transmitter nameplate or an old drawing.

2. Measure loop current

Measure current using the approved site method. Compare the measured mA with both the process condition and the analog-input raw value.

3. Check loop voltage

Confirm the transmitter still has enough terminal voltage at the actual loop current. Excess resistance can cause clipping near the top of span.

4. Check the AI channel

Verify channel type, input resistor or shunt arrangement, isolation, grounding and software scaling before replacing the transmitter.

5. Separate signal and process faults

If loop current matches the transmitter output but the engineering value is wrong, investigate scaling and input configuration before process instrumentation.

6. Record the final state

Capture measured current, terminal voltage, configured range, card channel and any barriers or isolators so the fault can be reproduced later.
