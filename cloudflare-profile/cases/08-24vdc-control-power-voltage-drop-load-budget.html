Control power planning

Check 24 VDC voltage margin before blaming the PLC or field device.

This calculator estimates DC cable voltage drop, endpoint voltage and supply headroom using values taken from the actual circuit. It is intended for remote I/O, transmitters, relays, solenoids and other control-panel loads.

Use measured or documented values. Enter conductor resistance from the cable datasheet and the minimum operating voltage from the actual device documentation. The calculation does not replace conductor ampacity, protective-device, hazardous-area or site electrical requirements.

Two-conductor DC estimate: loop resistance = 2 × one-way length × conductor resistance. Extra series resistance can represent known fuses, barriers, contacts or other measured/documented series elements.

Field checks that prevent false power-supply diagnoses

Measure under load

Open-circuit voltage can look normal while the endpoint collapses when the device energizes. Record both source and endpoint voltage at the real operating current.

Use the actual conductor resistance

Cable resistance changes with conductor size, material and temperature. Use the cable datasheet or a measured value instead of assuming a generic wire size.

Include series devices

Fuses, isolators, barriers, contacts, connectors and damaged terminals can add voltage loss that a cable-only calculation will miss.

Separate continuous load from inrush

A supply can be acceptable for steady load yet dip during relay, solenoid or capacitive input startup. Capture transient behavior when symptoms are intermittent.

Check shared commons and returns

Unexpected return-path resistance can create channel-to-channel symptoms. Measure voltage with reference to the correct supply return point.

Record minimum device voltage

The useful result is not only percentage drop. Compare the calculated and measured endpoint voltage with the device's documented operating requirement.
